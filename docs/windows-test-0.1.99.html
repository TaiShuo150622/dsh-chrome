Windows 测试说明书

0.1.99 DSH Desktop Chrome · 公开仓库 TaiShuo150622/dsh-chrome

1. 准备

  • Windows 10/11 x64
  • Chrome 或 Edge ≥ 116
  • 已安装并运行 DSH Harness
  • 不需要安装 Node

2. 获取文件

Release：v0.1.99-win-preview.1

  • dsh-desktop-chrome-0.1.99.tgz（DSH 插件，内含 host.exe）
  • dsh-chrome-extension-0.1.99.zip

3. 安装

  1. 解压 tgz，得到 package/ 目录。
  2. DSH → 插件 → 添加插件 → 输入 package 目录绝对路径。
  3. 启用 dsh-desktop-chrome，重启 DSH。
  4. Chrome → chrome://extensions → 开发者模式 → 加载已解压的扩展 → 选 dsh-chrome-extension/。
  5. 扩展 ID 应为 mejmgfhpgklcmphgimfbfohaodmjfmok。
  6. 完全退出 Chrome 再打开，popup 应显示 Connected。

0.1.99 起 provider 自动写 HKCU 注册表；0.1.93 及更早需要手动注册。

4. 报 “Specified native messaging host not found”

检查 manifest：

Test-Path "$env:USERPROFILE\.dsh\cache\dsh-chrome\native-messaging-hosts\com.deepseek.dsh.chrome.json"

查注册表：

reg query "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.deepseek.dsh.chrome" /ve

没有就手动注册（Chrome）：

reg add "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.deepseek.dsh.chrome" /ve /d "%USERPROFILE%\.dsh\cache\dsh-chrome\native-messaging-hosts\com.deepseek.dsh.chrome.json" /f

检查 host.exe：

Test-Path "$env:USERPROFILE\.dsh\cache\dsh-chrome\host\dsh-chrome-host.exe"

不存在就把 release 的 dsh-chrome-host-win32-x64.exe 复制成这个路径，重启 DSH，再完全退出/打开 Chrome。

5. 测试清单

A. 安装/连接

  • 扩展加载成功，ID 正确
  • popup Connected
  • 任务管理器有 dsh-chrome-host.exe
  • host.log 有 host started / bridge authenticated
  • 重启 Chrome/DSH 后重连

B. 基础工具（公开页面）

example.com · httpbin.org/forms/post · wikipedia.org

  • chrome_status
  • chrome_goto
  • chrome_snapshot
  • chrome_click
  • chrome_type（只用假数据）
  • chrome_screenshot
  • chrome_tabs
  • chrome_console / chrome_network

C. Windows 特有

  • 用户名/路径含空格或中文
  • 非管理员账户
  • 无黑色控制台闪窗
  • 未签名 exe 的 SmartScreen/杀毒提示
  • 非 C 盘安装
  • Edge 可选
  • 退出后无大量残留进程

D. headless

  • backend:"headless" 的 goto/snapshot/screenshot
  • chrome_headless_login {op:"show"} 可见窗口，finish 后恢复

E. 稳定性

  • 连续 50 次动作不断开
  • 切窗口后 chrome_resume
  • 中文/emoji、大页面
  • PDF 输出
  • 日志文件存在

不要输入真实密码、API key，不要付款。
